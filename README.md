# ospEDA

ospEDA is a MATLAB implementation of the *Orthogonal Subspace Projection-based Electrodermal Activity decomposition algorithm*.  

This method separates tonic and phasic components of the EDA signal.

# Quick Start

To see a basic example, simply run: run_OSP_Algorithm.m

# Reference
This work is based on the manuscript:
**Y. Lee, Y. Kong, and K. H. Chon**, "ospEDA: Orthogonal Subspace Projection for Electrodermal Activity Decomposition," submitted to IEEE Transactions on Affective Computing, 2025.
